# Flores para Kate

Proyecto listo para un repositorio independiente.

## Estructura que debe quedar en la raíz del repositorio

```text
index.html
styles.css
script.js
assets/
  musica.mp3
```

No subas la carpeta contenedora: sube **el contenido** directamente a la raíz del repositorio.

La música comienza al pulsar **Abrir detalle** y usa:

```text
./assets/musica.mp3
```

Si quieres cambiar la canción, reemplaza ese archivo conservando el mismo nombre.
